## **1\. Create Dense Layer (tf.keras.layers.Dense)**

### **Problem Solved**

Projects input features into a higher or lower-dimensional vector space using a fully connected matrix multiplication and bias addition.

### **Mental Trigger**

I need a learnable fully connected layer to project features into another representation space.

### **Primary APIs**

> * tf.keras.layers.Dense

### **Syntax**

`tf.keras.layers.Dense(`  
    `units,`  
    `activation=None,`  
    `use_bias=True,`  
    `kernel_initializer="glorot_uniform",`  
    `bias_initializer="zeros",`  
    `kernel_regularizer=None,`  
    `bias_regularizer=None,`  
    `activity_regularizer=None,`  
    `kernel_constraint=None,`  
    `bias_constraint=None,`  
    `**kwargs`  
`)`

### **Important Parameters**

> * units: Positive integer specifying the dimensionality of the output space.  
> * activation: Activation function to use. Defaults to linear (no activation).  
> * use\_bias: Boolean indicating whether the layer uses a bias vector.  
> * kernel\_initializer: Initializer for the embeddings/weights matrix.  
> * kernel\_regularizer: Regularizer function applied to the weight matrix.

### **Return Value**

A tensor of shape (batch\_size, ..., units) where all dimensions except the last match the input tensor shape.

### **Example**

`import tensorflow as tf`

`x = tf.random.normal([32, 128])`  
`dense_layer = tf.keras.layers.Dense(64, activation="relu")`  
`output = dense_layer(x)`  
`print(output.shape)  # (32, 64)`

### **Use When**

> * Building classification heads or regression output layers.  
> * Constructing multilayer perceptrons (MLPs) or feedforward networks.  
> * Projecting feature dimensions before or after attention mechanisms.

### **Avoid When**

> * Processing high-dimensional spatial data like images where local weight sharing is required (use Conv2D).  
> * Processing long sequential data where spatial/temporal context matters without explicit flattening.

### **Gotchas**

> * Dense operates on the last axis of the input tensor. Passing shape (32, 10, 128\) results in (32, 10, 64).  
> * Forgetting to flatten multidimensional feature maps prior to a final output Dense layer in legacy pipelines.  
> * Initializer defaults may cause vanishing or exploding gradients if paired with non-standard activations without adjusting initializers.  
> * Regularization loss must be tracked via layer.losses when using custom training loops without standard Keras Model compilation.

### **Performance Notes**

> * Highly optimized using BLAS libraries (cuBLAS on GPU, MKL/DNNL on CPU).  
> * Tensor contraction on rank greater than 2 inputs may introduce slight reshaping overheads.

### **Related APIs**

> * tf.keras.layers.EinsumDense  
> * tf.keras.activations.relu

### **PyTorch Equivalent**

tf.keras.layers.Dense → nn.Linear

### **Version Compatibility**

No significant changes in TensorFlow 2.x.

### **Search Metadata**

> * **Aliases**: Fully connected layer, Linear layer, MLP block  
> * **Common Search Terms**: tf.keras Dense layer, linear projection keras  
> * **Keywords**: dense, linear, affine, fully\_connected  
> * **Frequently Confused With**: Dense vs Conv1D (kernel size 1\)

### **Related Models**

> * bert  
> * logistic-regression

## **2\. Create 1D Convolution Layer (tf.keras.layers.Conv1D)**

### **Problem Solved**

Applies 1D cross-correlation over temporal or sequential feature representations to extract local invariant patterns.

### **Mental Trigger**

I need to extract local temporal or sequence patterns across a single spatial/time dimension.

### **Primary APIs**

> * tf.keras.layers.Conv1D

### **Syntax**

`tf.keras.layers.Conv1D(`  
    `filters,`  
    `kernel_size,`  
    `strides=1,`  
    `padding="valid",`  
    `data_format="channels_last",`  
    `dilation_rate=1,`  
    `groups=1,`  
    `activation=None,`  
    `use_bias=True,`  
    `kernel_initializer="glorot_uniform",`  
    `bias_initializer="zeros",`  
    `**kwargs`  
`)`

### **Important Parameters**

> * filters: Integer, the dimensionality of the output space.  
> * kernel\_size: Integer or tuple/list of 1 integer, specifying the length of the 1D convolution window.  
> * strides: Integer or tuple/list of 1 integer, specifying the stride length of the convolution.  
> * padding: String, "valid" (no padding), "same" (zero pad evenly), or "causal" (pad for autoregressive models).  
> * dilation\_rate: Integer or tuple/list of 1 integer, rate for dilated convolution.

### **Return Value**

A 3D tensor of shape (batch\_size, new\_steps, filters).

### **Example**

`import tensorflow as tf`

`x = tf.random.normal([16, 50, 64])  # (batch, time_steps, features)`  
`conv1d = tf.keras.layers.Conv1D(filters=32, kernel_size=3, padding="same", activation="relu")`  
`output = conv1d(x)`  
`print(output.shape)  # (16, 50, 32)`

### **Use When**

> * Extracting n-gram text features or processing speech waveforms.  
> * Processing time-series sensor data.  
> * Implementing causal dilated convolutions for autoregressive sequence models.

### **Avoid When**

> * Inputs have 2D spatial dimensions such as images or spectrograms with explicit height/width axes.  
> * Global context across long sequences is required without local window constraints.

### **Gotchas**

> * Setting padding="causal" is mandatory when modeling time-series to prevent future information leakage.  
> * Default data\_format is "channels\_last", shape must be (batch, steps, channels).  
> * High dilation rates without appropriate padding adjustments alter expected output sequence length.

### **Performance Notes**

> * Leverages cuDNN 1D convolution kernels on NVIDIA GPUs.  
> * Grouped convolutions (groups \> 1\) reduce parameter count and compute complexity.

### **Related APIs**

> * tf.keras.layers.SeparableConv1D  
> * tf.keras.layers.Conv2D

### **PyTorch Equivalent**

tf.keras.layers.Conv1D → nn.Conv1d

### **Version Compatibility**

No significant changes in TensorFlow 2.x.

### **Search Metadata**

> * **Aliases**: 1D Convolution, Temporal Convolution  
> * **Common Search Terms**: keras conv1d, 1d convolution sequence, causal conv1d  
> * **Keywords**: conv1d, temporal, time-series, causal, kernel\_size  
> * **Frequently Confused With**: Conv1D vs SimpleRNN

### **Related Models**

> * t5

### **Related Patterns**

## **3\. Create 2D Convolution Layer (tf.keras.layers.Conv2D)**

### **Problem Solved**

Applies 2D spatial cross-correlation to extract local hierarchical visual patterns from grid-like inputs.

### **Mental Trigger**

I need to extract spatial feature maps from images or 2D grid inputs.

### **Primary APIs**

> * tf.keras.layers.Conv2D

### **Syntax**

`tf.keras.layers.Conv2D(`  
    `filters,`  
    `kernel_size,`  
    `strides=(1, 1),`  
    `padding="valid",`  
    `data_format=None,`  
    `dilation_rate=(1, 1),`  
    `groups=1,`  
    `activation=None,`  
    `use_bias=True,`  
    `kernel_initializer="glorot_uniform",`  
    `bias_initializer="zeros",`  
    `**kwargs`  
`)`

### **Important Parameters**

> * filters: Integer, the output channel dimension.  
> * kernel\_size: An integer or tuple of 2 integers specifying height and width of the 2D window.  
> * strides: An integer or tuple of 2 integers specifying strides along height and width.  
> * padding: "valid" or "same".  
> * data\_format: "channels\_last" (default) or "channels\_first".

### **Return Value**

A 4D tensor with shape (batch, new\_height, new\_width, filters) when using "channels\_last".

### **Example**

`import tensorflow as tf`

`x = tf.random.normal([8, 224, 224, 3])  # (batch, height, width, channels)`  
`conv2d = tf.keras.layers.Conv2D(filters=64, kernel_size=(3, 3), padding="same", activation="relu")`  
`output = conv2d(x)`  
`print(output.shape)  # (8, 224, 224, 64)`

### **Use When**

> * Building Convolutional Neural Networks (CNNs) for image classification or object detection.  
> * Downsampling or projecting spatial representations in vision backbone networks.

### **Avoid When**

> * Spatial relations are unstructured, tabular, or pure set inputs.  
> * Parameters must be heavily restricted on edge devices (use DepthwiseConv2D or SeparableConv2D).

### **Gotchas**

> * padding="same" pads unevenly if kernel\_size is even and stride is odd, causing spatial shift subtle bugs.  
> * Expects 4D input tensor; passing 3D tensor (height, width, channels) raises shape errors.  
> * "channels\_first" requires explicit GPU layout support and non-default configuration.

### **Performance Notes**

> * Highly optimized via cuDNN. Tensor Cores execute 1/16/32-bit floating point convolutions efficiently when filter numbers are multiples of 8\.

### **Related APIs**

> * tf.keras.layers.DepthwiseConv2D  
> * tf.keras.layers.SeparableConv2D  
> * tf.keras.layers.Conv2DTranspose

### **PyTorch Equivalent**

tf.keras.layers.Conv2D → nn.Conv2d

### **Version Compatibility**

No significant changes in TensorFlow 2.x.

### **Search Metadata**

> * **Aliases**: 2D Convolution, CNN Layer  
> * **Common Search Terms**: keras conv2d, 2d convolution layer, image convolution tensorflow  
> * **Keywords**: conv2d, cnn, spatial, filters, kernel\_size  
> * **Frequently Confused With**: Conv2D vs SeparableConv2D

## **4\. Create 3D Convolution Layer (tf.keras.layers.Conv3D)**

### **Problem Solved**

Applies 3D spatial-temporal cross-correlation over volume or video sequence inputs.

### **Mental Trigger**

I need to extract features across 3D volumes like medical MRI scans or video frames over time.

### **Primary APIs**

> * tf.keras.layers.Conv3D

### **Syntax**

`tf.keras.layers.Conv3D(`  
    `filters,`  
    `kernel_size,`  
    `strides=(1, 1, 1),`  
    `padding="valid",`  
    `data_format=None,`  
    `dilation_rate=(1, 1, 1),`  
    `groups=1,`  
    `activation=None,`  
    `use_bias=True,`  
    `kernel_initializer="glorot_uniform",`  
    `**kwargs`  
`)`

### **Important Parameters**

> * filters: Integer, dimensionality of the output space.  
> * kernel\_size: Tuple of 3 integers specifying depth, height, and width of 3D window.  
> * strides: Tuple of 3 integers specifying strides along depth, height, and width.  
> * padding: "valid" or "same".

### **Return Value**

A 5D tensor with shape (batch, new\_depth, new\_height, new\_width, filters).

### **Example**

`import tensorflow as tf`

`x = tf.random.normal([4, 16, 112, 112, 3])  # (batch, depth/frames, height, width, channels)`  
`conv3d = tf.keras.layers.Conv3D(filters=32, kernel_size=(3, 3, 3), padding="same", activation="relu")`  
`output = conv3d(x)`  
`print(output.shape)  # (4, 16, 112, 112, 32)`

### **Use When**

> * Processing video clips (temporal stack of 2D images).  
> * 3D volumetric medical image segmentation (CT/MRI scans).

### **Avoid When**

> * Temporal frames can be processed independently via 2D CNN followed by RNN/Transformer.  
> * Hardware RAM is constrained (3D convolutions consume massive VRAM).

### **Gotchas**

> * 5D shape mismatches are common. Ensure channel dimension is placed last under "channels\_last".  
> * Substantial memory consumption can lead to GPU Out-Of-Memory (OOM) errors even at small batch sizes.

### **Performance Notes**

> * Significantly higher FLOP count and memory bandwidth requirements than 2D convolution. Always tune batch sizes conservatively.

### **Related APIs**

> * tf.keras.layers.Conv3DTranspose

## **5\. Create Depthwise Convolution (tf.keras.layers.DepthwiseConv2D)**

### **Problem Solved**

Performs spatial convolutions independently over each channel of the input, decoupling spatial filtering from channel projection.

### **Mental Trigger**

I need to apply spatial filtering without mixing channels to save computation and parameters.

### **Primary APIs**

> * tf.keras.layers.DepthwiseConv2D

### **Syntax**

`tf.keras.layers.DepthwiseConv2D(`  
    `kernel_size,`  
    `strides=(1, 1),`  
    `padding="valid",`  
    `depth_multiplier=1,`  
    `data_format=None,`  
    `dilation_rate=(1, 1),`  
    `activation=None,`  
    `use_bias=True,`  
    `**kwargs`  
`)`

### **Important Parameters**

> * kernel\_size: An integer or tuple of 2 integers specifying height and width of 2D spatial window.  
> * depth\_multiplier: The number of output channels generated per input channel.  
> * strides: Stride along height and width.  
> * padding: "valid" or "same".

### **Return Value**

A 4D tensor with shape (batch, new\_height, new\_width, in\_channels \* depth\_multiplier).

### **Example**

`import tensorflow as tf`

`x = tf.random.normal([8, 64, 64, 32])`  
`depth_conv = tf.keras.layers.DepthwiseConv2D(kernel_size=3, padding="same", depth_multiplier=1)`  
`output = depth_conv(x)`  
`print(output.shape)  # (8, 64, 64, 32)`

### **Use When**

> * Implementing MobileNet-style efficient lightweight vision architectures.  
> * Separating spatial feature extraction from channel cross-talk.

### **Avoid When**

> * Dense cross-channel feature interactions are required in a single computational pass.

### **Gotchas**

> * Does not accept a filters argument. Output channels are controlled strictly by in\_channels \* depth\_multiplier.  
> * Higher depth\_multiplier values negate parameter efficiency advantages.

### **Performance Notes**

> * Low FLOP footprint but can be memory-bandwidth bound on older hardware architectures due to lower operational intensity.

### **Related APIs**

> * tf.keras.layers.SeparableConv2D  
> * tf.keras.layers.Conv2D

### **PyTorch Equivalent**

tf.keras.layers.DepthwiseConv2D → nn.Conv2d (with groups=in\_channels)

### **Version Compatibility**

No significant changes in TensorFlow 2.x.

### **Search Metadata**

> * **Aliases**: Depthwise Convolution, Channel-wise Conv  
> * **Common Search Terms**: DepthwiseConv2D keras, mobilenet depthwise, channelwise convolution  
> * **Keywords**: depthwise, depth\_multiplier, lightweight, mobilenet  
> * **Frequently Confused With**: DepthwiseConv2D vs SeparableConv2D

## **6\. Create Separable Convolution (tf.keras.layers.SeparableConv2D)**

### **Problem Solved**

Executes a depthwise spatial convolution followed by a 1x1 pointwise convolution to drastically reduce parameters and compute cost.

### **Mental Trigger**

I want a drop-in replacement for Conv2D that uses significantly fewer parameters and operations.

### **Primary APIs**

> * tf.keras.layers.SeparableConv2D

### **Syntax**

`tf.keras.layers.SeparableConv2D(`  
    `filters,`  
    `kernel_size,`  
    `strides=(1, 1),`  
    `padding="valid",`  
    `data_format=None,`  
    `dilation_rate=(1, 1),`  
    `depth_multiplier=1,`  
    `activation=None,`  
    `use_bias=True,`  
    `**kwargs`  
`)`

### **Important Parameters**

> * filters: Integer output dimension for pointwise convolution.  
> * kernel\_size: Size of depthwise spatial kernel.  
> * depth\_multiplier: Number of depthwise channels per input channel.  
> * padding: "valid" or "same".

### **Return Value**

A 4D tensor with shape (batch, new\_height, new\_width, filters).

### **Example**

`import tensorflow as tf`

`x = tf.random.normal([8, 128, 128, 16])`  
`sep_conv = tf.keras.layers.SeparableConv2D(filters=64, kernel_size=3, padding="same")`  
`output = sep_conv(x)`  
`print(output.shape)  # (8, 128, 128, 64)`

### **Use When**

> * Building efficient architectures for mobile or edge deployment (e.g. Xception, MobileNet).  
> * Replacing heavy Standard 2D Convolutions in deep networks.

### **Avoid When**

> * Models are very small and underfitting is the primary concern.

### **Gotchas**

> * Dilation rate greater than 1 is not compatible with strides greater than 1 in depthwise separable layers.

### **Performance Notes**

> * Requires significantly fewer multiply-accumulate (MAC) operations compared to standard Conv2D.

### **Related APIs**

> * tf.keras.layers.DepthwiseConv2D  
> * tf.keras.layers.Conv2D

### **PyTorch Equivalent**

tf.keras.layers.SeparableConv2D → Combination of nn.Conv2d(..., groups=in\_channels) and nn.Conv2d(..., kernel\_size=1)

### **Version Compatibility**

No significant changes in TensorFlow 2.x.

### **Search Metadata**

> * **Common Search Terms**: SeparableConv2D keras, xception layer, efficient convolution  
> * **Keywords**: separable, mobilenet, xception, pointwise, depthwise

## **7\. Apply ReLU Activation (tf.keras.layers.ReLU)**

### **Problem Solved**

Applies Rectified Linear Unit activation *f*(*x*)=max(0,*x*) with optional thresholding, max values, and leaky slopes.

### **Mental Trigger**

I need a standard element-wise non-linear thresholding function zeroing out negative inputs.

### **Primary APIs**

> * tf.keras.layers.ReLU

### **Syntax**

`tf.keras.layers.ReLU(`  
    `max_value=None,`  
    `negative_slope=0.0,`  
    `threshold=0.0,`  
    `**kwargs`  
`)`

### **Important Parameters**

> * max\_value: Maximum activation value (e.g., 6.0 for ReLU6).  
> * negative\_slope: Slope for negative input values (defaults to 0.0).  
> * threshold: Threshold value for thresholded activation.

### **Return Value**

Tensor of the same shape and data type as input.

### **Example**

`import tensorflow as tf`

`x = tf.constant([-2.0, -0.5, 0.0, 3.0])`  
`relu_layer = tf.keras.layers.ReLU(max_value=6.0)`  
`output = relu_layer(x)`  
`print(output.numpy())  # [0. 0. 0. 3.]`

### **Use When**

> * Adding non-linearity in standard feedforward and CNN architectures.  
> * Creating bounded activations like ReLU6 by setting max\_value=6.0.

### **Avoid When**

> * Deep networks suffer from "dying ReLU" issues (use LeakyReLU or GELU).

### **Gotchas**

> * Setting max\_value changes non-saturating behavior for inputs above max\_value.

### **Performance Notes**

> * In-place or low-overhead point-wise kernel operation with minimal compute footprint.

### **Related APIs**

> * tf.keras.activations.relu  
> * tf.keras.layers.LeakyReLU

### **PyTorch Equivalent**

### **Version Compatibility**

## **8\. Apply Leaky ReLU Activation (tf.keras.layers.LeakyReLU)**

### **Problem Solved**

Allows a small non-zero gradient when input values are negative, preventing dead neuron units during optimization.

### **Mental Trigger**

I want ReLU activation, but need gradients to flow through negative inputs to prevent dead neurons.

### **Primary APIs**

> * tf.keras.layers.LeakyReLU

### **Syntax**

`tf.keras.layers.LeakyReLU(`  
    `negative_slope=0.2,`  
    `**kwargs`  
`)`

### **Important Parameters**

> * negative\_slope: Float parameter controlling the slope for negative inputs (default 0.2).

### **Return Value**

Tensor of the same shape and type as input.

### **Example**

`import tensorflow as tf`

`x = tf.constant([-2.0, 1.0, 3.0])`  
`leaky_relu = tf.keras.layers.LeakyReLU(negative_slope=0.1)`  
`output = leaky_relu(x)`  
`print(output.numpy())  # [-0.2  1.   3. ]`

### **Use When**

> * Training Generative Adversarial Networks (GANs) or deep CNNs prone to sparse zero gradients.

### **Avoid When**

> * Strict zero sparsity is desirable for memory savings or sparse kernel optimizations.

### **Gotchas**

> * Using an excessively large negative\_slope makes activation practically linear.

### **Performance Notes**

> * Equivalent execution speed to standard ReLU on modern hardware accelerators.

### **Related APIs**

> * tf.keras.layers.ReLU  
> * tf.keras.layers.PReLU

### **PyTorch Equivalent**

tf.keras.layers.LeakyReLU → nn.LeakyReLU

### **Version Compatibility**

In TF 2.x, alpha parameter was renamed to negative\_slope for standard consistency across Keras 3\.

### **Search Metadata**

> * **Aliases**: Leaky Rectified Linear Unit  
> * **Common Search Terms**: LeakyReLU keras, leaky relu activation tf  
> * **Keywords**: leaky\_relu, activation, alpha, negative\_slope

## **9\. Apply GELU Activation (tf.keras.activations.gelu)**

### **Problem Solved**

Weights inputs by their percentile value under a Gaussian distribution, providing smooth non-monotonic activation for transformer models.

### **Mental Trigger**

I need state-of-the-art smooth activation for Transformer blocks (BERT, ViT, GPT).

### **Primary APIs**

> * tf.keras.activations.gelu  
> * tf.keras.layers.Activation("gelu")

### **Syntax**

`tf.keras.activations.gelu(`  
    `x,`  
    `approximate=False`  
`)`

### **Important Parameters**

> * x: Input tensor.  
> * approximate: Boolean, whether to use fast tanh approximation.

### **Return Value**

Tensor of the same shape and dtype as x.

### **Problem Solved**

### **Primary APIs**

> * tf.keras.layers.Layer  
> * tf.range  
> * tf.math.sin / tf.math.cos

### **Syntax**

`class PositionalEncoding(tf.keras.layers.Layer):`  
    `def __init__(self, d_model, max_len=5000, **kwargs):`  
        `super().__init__(**kwargs)`  
        `...`

### **Important Parameters**

> * d\_model: Embedding projection hidden dimension.  
> * max\_len: Maximum sequence length precomputed for sinusoidal frequencies.

### **Return Value**

Tensor matching token input shape (batch, seq\_len, d\_model) with position signals added.

### **Example**

`import tensorflow as tf`  
`import numpy as np`

`class SinusoidalPositionalEncoding(tf.keras.layers.Layer):`  
    `def __init__(self, d_model, max_len=1000, **kwargs):`  
        `super().__init__(**kwargs)`  
        `self.d_model = d_model`  
        `position = np.arange(max_len)[:, np.newaxis]`  
        `div_term = np.exp(np.arange(0, d_model, 2) * -(np.log(10000.0) / d_model))`  
        `pe = np.zeros((max_len, d_model), dtype=np.float32)`  
        `pe[:, 0::2] = np.sin(position * div_term)`  
        `pe[:, 1::2] = np.cos(position * div_term)`  
        `self.pe = tf.constant(pe[np.newaxis, ...], dtype=tf.float32)`

    `def call(self, x):`  
        `seq_len = tf.shape(x)[1]`  
        `return x + self.pe[:, :seq_len, :]`

`x = tf.zeros([2, 10, 64])  # (batch, seq_len, d_model)`  
`pos_encoder = SinusoidalPositionalEncoding(d_model=64)`  
`output = pos_encoder(x)`  
`print(output.shape)  # (2, 10, 64)`

## **31\. Build Transformer Encoder Block (Keras Pattern)**

### **Problem Solved**

Assembles Multi-Head Self-Attention, Residual Connections, Layer Normalization, and Feed-Forward Networks into a reusable Encoder module.

> * tf.keras.layers.LayerNormalization  
> * tf.keras.layers.Dense  
> * tf.keras.layers.Dropout  
> * tf.keras.layers.Layer

### **Syntax**

`class TransformerEncoderBlock(tf.keras.layers.Layer):`  
    `def __init__(self, d_model, num_heads, dff, rate=0.1, **kwargs):`  
        `super().__init__(**kwargs)`  
        `...`

### **Important Parameters**

> * d\_model: Hidden size of model tokens.  
> * num\_heads: Number of multi-head attention projections.  
> * dff: Dimensionality of inner feedforward expansion layer.  
> * rate: Dropout rate.

### **Example**

`import tensorflow as tf`

`class TransformerEncoderBlock(tf.keras.layers.Layer):`  
    `def __init__(self, d_model, num_heads, dff, rate=0.1, **kwargs):`  
        `super().__init__(**kwargs)`  
        `self.mha = tf.keras.layers.MultiHeadAttention(num_heads=num_heads, key_dim=d_model // num_heads)`  
        `self.ffn = tf.keras.Sequential([`  
            `tf.keras.layers.Dense(dff, activation="relu"),`  
            `tf.keras.layers.Dense(d_model)`  
        `])`  
        `self.layernorm1 = tf.keras.layers.LayerNormalization(epsilon=1e-6)`  
        `self.layernorm2 = tf.keras.layers.LayerNormalization(epsilon=1e-6)`  
        `self.dropout1 = tf.keras.layers.Dropout(rate)`  
        `self.dropout2 = tf.keras.layers.Dropout(rate)`

    `def call(self, x, training=False):`  
        `attn_output = self.mha(query=x, value=x, key=x)`  
        `attn_output = self.dropout1(attn_output, training=training)`  
        `out1 = self.layernorm1(x + attn_output)`

        `ffn_output = self.ffn(out1)`  
        `ffn_output = self.dropout2(ffn_output, training=training)`  
        `return self.layernorm2(out1 + ffn_output)`

`x = tf.random.normal([2, 16, 64])`

## **32\. Build Transformer Decoder Block (Keras Pattern)**

### **Problem Solved**

Combines Causal Masked Self-Attention, Cross-Attention (Encoder-Decoder attention), Layer Normalization, and Feed-Forward Networks for autoregressive generation.

### **Mental Trigger**

I need a Transformer Decoder layer supporting causal autoregressive sequence generation.

### **Primary APIs**

> * tf.keras.layers.MultiHeadAttention  
> * tf.keras.layers.LayerNormalization  
> * tf.keras.layers.Dense

### **Syntax**

`class TransformerDecoderBlock(tf.keras.layers.Layer):`  
    `def __init__(self, d_model, num_heads, dff, rate=0.1, **kwargs):`  
        `super().__init__(**kwargs)`  
        `...`

### **Important Parameters**

> * d\_model: Token representation hidden dimensionality.  
> * num\_heads: Number of parallel attention heads.  
> * dff: Expansion dimension of feed-forward sub-layer.

### **Return Value**

Autoregressively processed sequence representation tensor.

### **Example**

`import tensorflow as tf`

`class TransformerDecoderBlock(tf.keras.layers.Layer):`  
    `def __init__(self, d_model, num_heads, dff, rate=0.1, **kwargs):`  
        `super().__init__(**kwargs)`  
        `self.self_attn = tf.keras.layers.MultiHeadAttention(num_heads=num_heads, key_dim=d_model // num_heads)`  
        `self.cross_attn = tf.keras.layers.MultiHeadAttention(num_heads=num_heads, key_dim=d_model // num_heads)`  
        `self.ffn = tf.keras.Sequential([`  
            `tf.keras.layers.Dense(dff, activation="relu"),`  
            `tf.keras.layers.Dense(d_model)`  
        `])`  
        `self.norm1 = tf.keras.layers.LayerNormalization(epsilon=1e-6)`  
        `self.norm2 = tf.keras.layers.LayerNormalization(epsilon=1e-6)`  
        `self.norm3 = tf.keras.layers.LayerNormalization(epsilon=1e-6)`

    `def call(self, x, enc_output, training=False):`  
        `# Causal Self-Attention`  
        `sa_out = self.self_attn(query=x, value=x, key=x, use_causal_mask=True)`  
        `x = self.norm1(x + sa_out)`

        `# Cross Attention against encoder outputs`  
        `ca_out = self.cross_attn(query=x, value=enc_output, key=enc_output)`  
        `x = self.norm2(x + ca_out)`

        `# Feed Forward Network`  
        `ffn_out = self.ffn(x)`  
        `return self.norm3(x + ffn_out)`

`x = tf.random.normal([2, 8, 64])          # Target sequence`  
`enc_out = tf.random.normal([2, 16, 64])  # Source sequence`  
`dec_block = TransformerDecoderBlock(d_model=64, num_heads=4, dff=256)`  
`output = dec_block(x, enc_output=enc_out)`  
`print(output.shape)  # (2, 8, 64)`

### **Problem Solved**

### **Syntax**

    `def __init__(self, **kwargs):`  
        `super().__init__(**kwargs)`

    `def build(self, input_shape):`  
        `# Create trainable weights here`  
        `super().build(input_shape)`

    `def call(self, inputs, **kwargs):`  
        `# Forward pass computation`  
        `return outputs`

    `def get_config(self):`  
        `# For serialization`  
        `config = super().get_config()`  
        `return config`

### **Important Parameters**

> * input\_shape: TensorShape instance passed into build() automatically on first call.

### **Return Value**

Output tensor or structure computed by custom forward logic.

### **Example**

`import tensorflow as tf`

`class LinearScaleBias(tf.keras.layers.Layer):`  
    `def __init__(self, units=32, **kwargs):`  
        `super().__init__(**kwargs)`  
        `self.units = units`

    `def build(self, input_shape):`  
        `self.w = self.add_weight(`  
            `shape=(input_shape[-1], self.units),`  
            `initializer="random_normal",`  
            `trainable=True,`  
            `name="w"`  
        `)`  
        `self.b = self.add_weight(`  
            `shape=(self.units,),`  
            `initializer="zeros",`  
            `trainable=True,`  
            `name="b"`  
        `)`  
        `super().build(input_shape)`

    `def call(self, inputs):`  
        `return tf.matmul(inputs, self.w) + self.b`

    `def get_config(self):`  
        `config = super().get_config()`  
        `config.update({"units": self.units})`  
        `return config`

`x = tf.random.normal([4, 16])`  
`layer = LinearScaleBias(units=8)`  
`out = layer(x)`  
`print(out.shape)  # (4, 8)`
